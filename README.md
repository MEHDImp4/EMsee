Clône de Twitter
• Description : Créer une application similaire à Twitter où les utilisateurs peuvent
publier des tweets, suivre des utilisateurs et réagir aux tweets.
• Fonctionnalités :
o Publication de tweets et suivi d’autres utilisateurs.
o Système de likes et de retweets.
o Profil utilisateur.
o Authentification.
• Bonus: Ajout de hashtags, mentions, et notifications en temps réel, mode vacances pour
désactiver les notifications, intégration avec Spotify pour partager la musique écoutée.
• Technologies : JavaScript, React, TypeScript.
